**New function: `cis_overlap(ci_a: tuple[float, float], ci_b: tuple[float, float]) -> bool`**
- Returns True if the two 95% Wilson CIs overlap: `ci_a[0] <= ci_b[1] and ci_b[0] <= ci_a[1]`

   `*Sweep: {sweep_date} · {model_count} models · n={trials_per_level} trials per level*`
   Use the passed args; if sweep_date is empty, omit the metadata line.

   Add a footnote after the table: `*† Statistical tie: overlapping 95% CI at T0.*`

Keep all existing behavior (grading logic, CI formatting, rubric footer). Line length ≤ 100 chars (ruff enforced).

Create `scripts/generate_readme_results.py` as a standalone CLI script. The script is the canonical way to regenerate RESULTS.md after any sweep.

**Script behavior:**

```python
#!/usr/bin/env python3
"""Generate results/RESULTS.md from the latest sweep directory.

Usage:
    uv run python scripts/generate_readme_results.py
    uv run python scripts/generate_readme_results.py --sweep results/sweep_20260318
    uv run python scripts/generate_readme_results.py --out results/RESULTS.md
"""
import argparse
import json
from pathlib import Path

from modelforecast.output.markdown_report import (
    find_latest_sweep_dir,
    write_markdown_report,
)
```

**Argument parsing:**
- `--sweep PATH`: explicit sweep directory (default: auto-detect latest via `find_latest_sweep_dir`)
- `--out PATH`: output file path (default: `results/RESULTS.md`)
- `--base PATH`: base results directory for auto-detection (default: `results/`)

**Reading sweep files:**
1. Find sweep dir (via arg or auto-detect)
2. Try to read `sweep_manifest.json` in the sweep dir for metadata; if absent, compute from files
3. Glob `*.json` in sweep dir, skip `sweep_manifest.json` and `checkpoint.json`
4. For each JSON file, load and build `results` dict keyed by filename stem (e.g., `"nvidia_nemotron-nano-9b-v2_free__level_0"`)
5. Extract `sweep_date` from `sweep_dir.name` — strip `sweep_` prefix: `sweep_20260318` → `"2026-03-18"`
6. Count distinct models from loaded result `probes.model` values for `model_count`
7. Extract `trials_per_level` from manifest `trials_per_level` field; default 10

**Write output:**
- Call `write_markdown_report(output_dir=out_path.parent, results=results, sweep_date=sweep_date, model_count=model_count, trials_per_level=trials_per_level)`
- The function writes to `output_dir/RESULTS.md`; if `--out` points elsewhere, rename after writing OR pass `output_dir` and `filename` separately. Simplest: write to `results/RESULTS.md` unconditionally (hardcode the path the function writes to, move if --out differs)
- Print `[green]✓ Wrote {out_path}[/]` via `rich.console.Console()`

**After writing the script, run it:**
```bash
cd /home/jw/dev/modelforecast && uv run python scripts/generate_readme_results.py
```
This regenerates `results/RESULTS.md` from the latest available sweep data.
