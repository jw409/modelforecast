- B: T0 >= 60%, T1 >= 50%, no probe below 30%

    }

**Function: `build_quick_answer_section(model_summary: dict) -> str`**

Returns markdown for the QUICK-ANSWER block:
1. Find the top-graded model: prefer grade A, then B. Among ties, pick highest T0 rate at level 0.
   If no model with grade A or B exists, pick the highest-grade model overall.
2. Build shields.io badge: `![Grade A](https://img.shields.io/badge/Grade-A-brightgreen)` — color map:
   A=brightgreen, B=green, C=yellow, D=orange, F=red
3. Return:
   ```
   ### Best free model right now: {short_model}

   ![Grade {grade}](https://img.shields.io/badge/Grade-{grade}-{color}) — scores {grade} across all tool-calling dimensions. Free on OpenRouter.

   > Use [`{model_id}`](https://openrouter.ai/models/{model_id_no_free}) for tool calling in your agent pipeline.

   Full results: [results/RESULTS.md](results/RESULTS.md) · [Methodology](METHODOLOGY.md)
   ```
   Where `short_model = model_id.split("/")[-1].replace(":free", "")`.

**Function: `build_category_winners_section(model_summary: dict) -> str`**

Returns markdown for the CATEGORY-WINNERS block. Derive category winners from existing T/R/A scores — no new probes needed:

- **Best for tool calling (T0+T1)**: model with highest average of `level_0.rate + level_1.rate` among grade A/B models
- **Best for schema compliance (T1)**: model with highest `level_1.rate` among models that have level 1 data
- **Best for restraint (R0)**: model with highest `level_4.rate` among models that have level 4 data
- **Best for multi-turn agency (A1)**: model with highest `level_3.rate` among models that have level 3 data

For each category, emit one line:
`- **Best for {category}**: [{short_model}](https://openrouter.ai/models/{model_id_no_free}) — {rate}% T{N}`

If fewer than 2 models have data for a category, skip that category line (don't emit incomplete recommendations).

**Function: `build_avoid_section(model_summary: dict) -> str`**

Returns markdown for the AVOID block:

Find all models where grade == "F" (T0 < 20%). For each:
- Determine failure mode label from `failure_modes` list:
  - Most common item in the list, or "no tool_call produced" if list is empty
- Emit: `- **{short_model}**: {failure_mode} (T0={rate}%)`

Header:
```
### Avoid these models for tool calling

These models fail the basic tool invocation test (T0 < 20%). They will silently fail your agent pipeline.
```

If no F-grade models, emit:
```
### Avoid these models for tool calling

No models scored F in this sweep.
```

**Function: `grade_badge_markdown(model_id: str, grade: str) -> str`**

Helper. Returns inline badge markdown:
`[![Grade {grade}](https://img.shields.io/badge/Grade-{grade}-{color})](https://openrouter.ai/models/{model_id_no_free})`

**Function: `build_grade_badges_section(model_summary: dict) -> str`**

Returns markdown for the GRADE-BADGES block. Emit one badge per grade-A and grade-B model, then a text line:

```
### Top performers

{badge1} {badge2} {badge3}

*Click a badge to view the model on OpenRouter.*
```

from modelforecast.output.readme_sections import update_readme_sections

# Build model_summary from the results dict already loaded
model_summary = {}
for result_key, result_data in results.items():
    if not isinstance(result_data, dict) or "probes" not in result_data:
        continue
    model = result_data["probes"]["model"]
    level = result_data["probes"]["level"]
    if model not in model_summary:
        model_summary[model] = {"level_results": {}, "failure_modes": []}
    model_summary[model]["level_results"][level] = result_data
    # Collect failure modes from trial data if present
    for trial in result_data.get("probes", {}).get("trials", []):
        if fm := trial.get("failure_mode"):
            model_summary[model]["failure_modes"].append(fm)

# Calculate grades
from modelforecast.output.markdown_report import calculate_grade
for model_data in model_summary.values():
    model_data["grade"] = calculate_grade(model_data["level_results"])

sweep_metadata = {
